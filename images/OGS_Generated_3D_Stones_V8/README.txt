OGS GENERATED 3D STONES V8

white/ : 540 white stones, 512 x 512 RGBA PNG
black/ : 150 black stones, 768 x 768 RGBA PNG

The images are derived directly from the ten high-quality generated single-stone images from the chat, not from the previously defective V6/V7 stone assets. There are five distinct source stone designs for each color. The numbered images are different crop/texture orientation and lighting-normalized variations of these originals, not 540 or 150 separately generated source designs. The first five files of each color preserve their source orientation.

The source PNGs were resampled within the original stone's circular face and have new clean antialiased alpha masks, removing stray colored pixels outside the stone.
